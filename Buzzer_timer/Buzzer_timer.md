
# کلاس Buzzer

این کلاس برای کنترل یک بازر (Buzzer) با استفاده از میکروکنترلر STM32 طراحی شده است. با استفاده از این کلاس می‌توانید بازر را روشن و خاموش کنید، تعداد چشمک‌ها (Blink)، مدت زمان روشن بودن (Ton) و مدت زمان خاموش بودن (Toff) را تنظیم نمایید.

---

## ویژگی‌ها
- تنظیم تعداد چشمک‌ها (BlinkCount).
- تنظیم مدت زمان روشن بودن بازر (Ton).
- تنظیم مدت زمان خاموش بودن بازر (Toff).
- امکان معکوس کردن منطق روشن و خاموش شدن (invertLogic).

---

## نحوه استفاده

### سازنده کلاس

```cpp
Buzzer(GPIO_TypeDef* BuzzerPort, 
       uint16_t BuzzerPin, 
       uint32_t BlinkCount = 1, 
       uint32_t Ton = 100, 
       uint32_t Toff = 100, 
       bool invertLogic = false);
```
### توضیحات پارامترها:

- `BuzzerPort`: پورتی که بازر به آن متصل شده است (مثلاً `GPIOA`).
- `BuzzerPin`: شماره پین GPIO که بازر به آن متصل شده است.
- `BlinkCount`: تعداد چشمک‌هایی که بازر باید بزند (پیش‌فرض: ۱).
- `Ton`: مدت زمان روشن بودن بازر به میلی‌ثانیه (پیش‌فرض: ۱۰۰).
- `Toff`: مدت زمان خاموش بودن بازر به میلی‌ثانیه (پیش‌فرض: ۱۰۰).
- `invertLogic`: اگر مقدار `true` باشد، منطق روشن/خاموش شدن معکوس می‌شود.

---

### متدها

#### `void on()`
بازر را روشن می‌کند و حالت چشمک‌زدن را فعال می‌سازد.

#### `void off()`
بازر را خاموش می‌کند و شمارنده‌ها را بازنشانی می‌کند.

#### `void handle()`
این متد باید در یک تایمر ۱ میلی‌ثانیه‌ای فراخوانی شود. وظیفه آن مدیریت روشن و خاموش شدن بازر بر اساس مقادیر `Ton`، `Toff` و `BlinkCount` است.

---

## مثال استفاده

```cpp
#include "Buzzer.h"

// تعریف بازر
Buzzer myBuzzer(GPIOA, GPIO_PIN_5, 5, 200, 300, false);

// تعریف تایمر 1 میلی‌ثانیه‌ای
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM2) // تایمر 2
    {
        // فراخوانی متد handle
        myBuzzer.handle();
    }
}

void main()
{
    // مقداردهی اولیه تایمر
    HAL_TIM_Base_Start_IT(&htim2);

    // روشن کردن بازر
    myBuzzer.on();

    // حلقه اصلی
    while (1)
    {
        // سایر کدهای برنامه
    }
}
```

---

## نکات
1. متد `handle` باید در یک تایمر با دقت ۱ میلی‌ثانیه فراخوانی شود.
2. برای خاموش کردن بازر و بازنشانی حالت‌ها از متد `off` استفاده کنید.
3. اگر از منطق معکوس استفاده می‌کنید (مثلاً زمانی که بازر با منطق Active-Low کار می‌کند)، مقدار `invertLogic` را به `true` تنظیم کنید.
