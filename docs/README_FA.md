## معرفی

Raymon-Lib-STM32 مخزنی برای کدها و اجزای قابل‌بازاستفاده به زبان C++ در توسعهٔ سیستم‌های نهفته مبتنی بر میکروکنترلرهای STM32 است.

این پروژه در حال توسعه است. برای تشخیص قابلیت‌های واقعاً پیاده‌سازی‌شده، فایل‌های منبع و تاریخچهٔ مخزن را بررسی کنید؛ پشتیبانی از یک وسیلهٔ جانبی، خانوادهٔ میکروکنترلر یا قابلیت خاص را بدون مشاهدهٔ پیاده‌سازی فرض نکنید.

## شروع کار

1. مخزن را دریافت یا کلون کنید.
2. پیش از ادغام کتابخانه، فایل‌های منبع و تنظیمات مرتبط با پروژه را بررسی کنید.
3. کتابخانه را در یک پروژهٔ STM32 با ابزارهای سازگار استفاده کنید و میکروکنترلر هدف، کد راه‌اندازی، linker script و مقداردهی اولیهٔ وسایل جانبی را متناسب با پروژه تنظیم کنید.
4. پیش از استفاده در محصول نهایی، برنامه را روی سخت‌افزار واقعی بسازید و آزمایش کنید.

در این README دستور ساخت عمومی ارائه نشده است؛ روش ساخت به ساختار پروژهٔ مصرف‌کننده و تنظیمات toolchain بستگی دارد.

## سازگاری

- **سکوی هدف:** میکروکنترلرهای STM32؛ مدل‌های دقیق پشتیبانی‌شده به کد و تنظیمات موجود بستگی دارند.
- **زبان:** C++.
- **ابزار ساخت:** ابزارهایی که با میکروکنترلر هدف و کد مخزن سازگار باشند.

## وضعیت پروژه

این سند معرفی کلی مخزن است. برای تعیین رفتار واقعی، کد منبع را مرجع اصلی قرار دهید. رفتار وابسته به سخت‌افزار، زمان‌بندی، مصرف حافظه و سازگاری با وسایل جانبی باید در محیط هدف بررسی شود.

## مشارکت

برای گزارش خطا یا پیشنهاد اصلاح، از GitHub Issues و Pull Requests استفاده کنید. در گزارش خطا، مدل میکروکنترلر، نسخهٔ ابزار ساخت، مراحل بازتولید و خروجی مرتبط build را ذکر کنید. تغییرات را محدود و متمرکز نگه دارید و در صورت امکان روی سخت‌افزار واقعی آزمایش کنید.
